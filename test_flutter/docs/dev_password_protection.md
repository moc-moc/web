# 開発環境パスワード保護について

このドキュメントでは、開発中のアプリに設定したパスワード保護の仕組みと管理方法を説明します。

## 概要

開発中のアプリが一般公開されないように、シンプルなパスワード保護機能を実装しました。
ユーザーがアプリにアクセスすると、まずパスワード入力画面が表示され、正しいパスワードを入力しないとアプリを使用できません。

## 仕組み

1. **認証ページ**: `web/auth-check.html`
   - ユーザーにパスワード入力を求める専用ページ
   - 正しいパスワードが入力されると、セッションストレージに認証フラグを保存
   - メインアプリにリダイレクト

2. **認証チェック**: `web/index.html`の先頭に追加されたスクリプト
   - ページ読み込み時にセッションストレージの認証フラグをチェック
   - 認証されていない場合は`auth-check.html`にリダイレクト

3. **キャッシュ制御**: `firebase.json`の設定
   - `auth-check.html`がキャッシュされないように設定
   - 常に最新の認証ページが表示される

## 現在のパスワード

```
dev2024
```

**重要**: このパスワードは`web/auth-check.html`の以下の行で設定されています：

```javascript
const DEV_PASSWORD = 'dev2024';
```

## パスワードの変更方法

1. `web/auth-check.html`を開く
2. 以下の行を見つけて、パスワードを変更する：
   ```javascript
   const DEV_PASSWORD = 'dev2024'; // ← ここを変更
   ```
3. ファイルを保存
4. アプリをビルド＆デプロイ：
   ```bash
   flutter build web
   firebase deploy --only hosting
   ```

## 本番環境への切り替え方法

アプリが完成して一般公開する準備ができたら、以下の手順でパスワード保護を無効化します：

### 方法1: 開発フラグをオフにする（推奨）

1. `web/index.html`を開く
2. 以下の行を見つけて`true`を`false`に変更：
   ```javascript
   const isDevelopment = true; // ← false に変更
   ```
3. ビルド＆デプロイ：
   ```bash
   flutter build web
   firebase deploy --only hosting
   ```

### 方法2: 認証コードを完全に削除する

1. `web/index.html`から認証チェックのスクリプト全体を削除
2. `web/auth-check.html`を削除（任意）
3. `firebase.json`から`headers`セクションを削除（任意）
4. ビルド＆デプロイ

## セキュリティに関する注意事項

### ⚠️ この方法の制限

- **クライアントサイドのみの保護**: パスワードはブラウザ上のJavaScriptに平文で記述されています
- **技術的な知識があれば回避可能**: ブラウザの開発者ツールでソースコードを見れば、パスワードが分かります
- **セッション単位の認証**: ブラウザを閉じるとセッションストレージがクリアされ、再度パスワード入力が必要になります

### ✅ この方法が適している場合

- 開発中の簡易的な非公開化
- 検索エンジンのインデックス化を防ぐ
- 一般ユーザーの偶発的なアクセスを防ぐ
- 内部チームやテスターへの簡単な共有

### 🔒 より強固な保護が必要な場合

機密性の高いデータや本格的なアクセス制御が必要な場合は、以下の方法を検討してください：

1. **Firebase Authentication**: ユーザー認証を実装
2. **Cloud Functions for Firebase**: サーバーサイドで認証チェック
3. **Firebase Hosting のリダイレクト**: 特定のユーザーのみアクセス可能に設定
4. **Firestore Security Rules**: データベースレベルでのアクセス制御

## トラブルシューティング

### パスワードを入力してもアクセスできない

1. ブラウザのキャッシュをクリアしてください
2. シークレットモード/プライベートブラウジングで試してください
3. 正しいパスワードが設定されているか確認してください

### パスワード保護が機能しない

1. `web/index.html`の`isDevelopment`が`true`になっているか確認
2. 最新のビルドがデプロイされているか確認
3. ブラウザのコンソールでエラーが出ていないか確認

### パスワードを忘れた場合

`web/auth-check.html`を開いて、`DEV_PASSWORD`の値を確認してください。

## まとめ

この機能により、開発中のアプリは簡単なパスワードで保護されます。
一般ユーザーが偶発的にアクセスすることを防ぎ、内部テストや開発作業を安心して進められます。

本番リリース時は必ず`isDevelopment`を`false`に変更することを忘れないでください！
