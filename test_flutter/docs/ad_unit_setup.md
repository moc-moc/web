# 広告ユニットIDの作り方（Google AdMob）

初心者の方でも迷わないように、必要な作業をステップごとにまとめました。  
Android・iOSの両方に対応する想定です。

## 1. 事前準備
1. **Googleアカウント** を用意する（業務用の共用アカウント推奨）
2. [AdMob](https://admob.google.com/) にアクセスし、利用規約へ同意
3. 振込先情報（口座）と請求元情報を設定（後からでも可）

## 2. アプリをAdMobに登録
1. AdMobダッシュボード左メニューから **アプリ** → **アプリを追加** を選択
2. 「アプリをストアに公開済みですか？」に対して
   - まだ公開していなければ **いいえ** → アプリ名を手入力
3. プラットフォームを **Android** または **iOS** で作成  
   両方に出す場合は、同名アプリを2件登録する（片方作成後、再度追加）
4. 追加するとアプリ詳細画面に遷移する

## 3. 広告ユニットを作成
アプリごとに複数の広告ユニットを持てます。今回必要なのは以下の3種類:

| 用途 | 推奨フォーマット | 備考 |
| --- | --- | --- |
| フレンド投稿間 | ネイティブ（テンプレート Medium） | ポストカードと同じ大きさ |
| トラッキング画面（カメラOFF） | ネイティブ + 動画 | 280pxのプレビュー領域に表示 |
| トラッキング画面（カメラON） | バナー（Large Banner） | Stopボタンのさらに下に表示 |

作成手順:
1. アプリ詳細画面で **広告ユニットを追加** をクリック
2. フォーマットを選択（ネイティブ or バナー）
3. 名前をわかりやすく付ける（例：`friend_feed_native`）
4. 完了すると **広告ユニットID** が表示されるのでメモしておく
5. Android / iOS それぞれで同じ構成になるよう3種類ずつ作成

> **メモ**: 実アカウント開設直後は広告配信まで最大1時間ほどかかります。

## 4. Flutter側にIDを設定
1. `lib/core/ads/ad_helper.dart` のテストIDを取得したIDに差し替え  
   ```dart
   static const _friendFeedNative = _AdUnitConfig(
     androidId: 'ここにAndroidのID',
     iosId: 'ここにiOSのID',
   );
   ```
2. `flutter pub get` を実行（依存関係が最新であることを確認）
3. 物理端末またはエミュレータで `flutter run` を実行
4. 広告が表示されるか確認し、表示回数が0のままならば
   - 端末がネットワークに接続されているか
   - GDPR/年齢制限のコンプライアンス設定が必要か
   を確認

## 5. よくあるエラー
- **広告が表示されない/空白**: 作成したばかりの場合は最大1時間待つ。テストIDで動くか先に確認
- **`Ad failed to load` エラーコード 3**: フィルレート不足。アプリが審査中のときによく発生
- **iOSでクラッシュ**: `Info.plist` に `GADApplicationIdentifier` を入れ忘れている可能性あり

これで実際の広告ユニットIDを差し込む準備が整います。
